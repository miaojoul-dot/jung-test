# 荣格八维测试 · 大白话版

> 将专业的荣格八维认知功能测试，彻底翻译成「人人都能听懂」的大白话。

## 项目简介

本测试基于荣格八维理论（Ni, Ne, Si, Se, Ti, Te, Fi, Fe），通过 **72 道题目** 测量你大脑的八个认知功能偏好。每道题目下方都附有一句**生活化的大白话转述**，告别晦涩术语，让你真正看懂自己在问什么。

测试结束后，你将获得：
- 八项认知功能的得分柱状图
- 最可能的 MBTI 类型（如 INTJ、INFP 等）
- 该类型的**优点与注意点**（两列对比）
- **适合的职业方向**建议
- 可能匹配的其他类型

## 特色亮点

- **全白话文**：题干 + 独立大白话转述，不绕弯子，不用“比如”。
- **72 道精准题目**：每道题对应正确的荣格八维维度，语义经过逐条核对。
- **结果页直观**：八维得分条形图、优缺点两列布局、职业建议。
- **无广告、无跟踪**：纯静态网页，可托管在 GitHub Pages 或其他静态服务器。
- **开箱即用**：一个 `index.html` 文件，包含全部样式和逻辑。
